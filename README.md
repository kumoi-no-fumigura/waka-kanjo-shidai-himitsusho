## 作品について

和歌の起こりを二神の唱和から説き、人麿・赤人の故事や歌の病、歌の祖神などを記した、和歌の秘伝を授ける灌頂の書。ここの本文は国立国会図書館所蔵の写本により、末尾に相模での書写を記す奥書がある。

## 本文の作り方

国立国会図書館の公開画像を、国立国会図書館の NDL古典籍OCR-Lite でテキスト化し、原本のページごとに段落に分けました。写本の崩し字の OCR なので、誤りが多く残っています。

## ファイル

| パス | 中身 |

| `honbun/` | 本文。1 行が 1 段落で、`段落ID<TAB>本文` の形です。原本の行の切れ目は ⏎ で示しています（⏎ は改行の印で、本文の字ではありません）。50段落ごとにファイルを分けています（1ファイル）。 |

## 誤りを見つけたら
